# QueueGo 项目源码归集说明

本次将当前环境保留的 QueueGo 前端、早期 queue-platform-app 版本的后端示例、H5 演示、用户提供的 18 张 UI 设计图及架构文档统一放入 `/home/ubuntu/queuego-app`，并打包交付。没有重新开发或验证完整业务系统。

## 文件内容

- `src/`：Uni-app + Vue 3 前端，16 个页面及 2 个通用组件；包含中英文语言文件、主题样式和状态管理代码。
- `manifest.json`、`pages.json`、`package.json`、`vite.config.js`：原有项目配置。
- `uniCloud/database/`：5 份早期数据库结构文件，按原样保留。
- `uniCloud/cloudfunctions/`：5 个早期云函数示例，分别为订单创建、队列查询、商家列表、支付退款和商家通知。保留原有单文件格式，尚非标准可直接上传的云函数目录结构。已有空目录不表示对应功能已经实现。
- `demo/`：独立 H5 演示 `index.html` 和 `styles.css`。它不是 Uni-app 源码构建产物，也没有接通实际 uniCloud 后端。
- `ui-designs/`：18 张用户提供的 WebP UI 设计参考图，不是本次运行截图。
- `docs/`：用户提供的项目架构设计文档，描述目标方案，不代表全部内容已经实现。
- `FILE_MANIFEST.sha256`：除清单自身外，各交付文件的 SHA-256 校验清单。

## H5 演示查看方式

```bash
cd /home/ubuntu/queuego-app/demo
python3 -m http.server 8080
```

在本机浏览器打开 `http://localhost:8080`。解压到其他目录时，请相应调整路径。
